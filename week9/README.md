# 9-зертханалық жұмыс: камера және LookAt

## Мақсаты

Бес кубы бар 3D сахнаға еркін жүретін камера қосу. Камераның қозғалысы кадр уақытына (delta time) тәуелді, сондықтан кадр жиілігі өзгергенде оның бір секундтағы жылдамдығы тұрақты қалады.

## Басқару

| Перне | Әрекет |
|---|---|
| W / S | Алға / артқа |
| A / D | Камераның оң / сол жағына |
| Space / Left Shift | Жоғары / төмен |
| Left Ctrl | Қозғалысты екі есе жылдамдату |
| M | Тұрақты нысана мен камера бағытына қарауды салыстыру |
| R | Камераны бастапқы орнына қайтару |
| P | Камера координаттарын консольге шығару |
| Esc | Бағдарламадан шығу |

Камера бастапқыда (0, 0, 3) нүктесінде. Бес кубтың орындары мен қозғалысы камерадан бөлек қалады. Space және Shift әлемнің Y бағытымен қозғалады; камера осы жұмыста еңкеймейтіндіктен, ол camUp бағытымен бірдей.

## Екі LookAt нұсқасы

Әдепкі нұсқа:

    glm::lookAt(camPos, camPos + camFront, camUp);

Нысана камерамен бірге жылжиды. Сондықтан W/S камераны алға-артқа, A/D камераны оңға-солға жылжытады және көрініс ұшу бағытына қарайды.

M арқылы салыстыру режиміне ауысқанда екінші аргумент әлемнің тұрақты координат басы болады:

    glm::lookAt(camPos, glm::vec3(0.0f), camUp);

Бұл режимде камера әрдайым координат басына қарайды. W/S басқанда арақашықтық жақындайды не алыстайды. A/D басқанда камера нысананы айнала доға бойымен қозғалып, орбита жасайды. Мұндай режим 3D редакторда не CAD бағдарламасында объектіні барлық жағынан көруге пайдалы.

## Есеп

camPos, camFront, camUp негізгі циклден тыс жарияланған. Әр кадрда dt = now - lastFrame есептеліп, пернетақта өңдеуіне беріледі. Негізгі жылдамдық 2.5 * dt; Ctrl басылғанда көбейткіш 2 болады. A/D үшін бүйір бағыт normalize(cross(camFront, camUp)) арқылы табылады.

view матрицасы әр кадрда жасалады. Кубты тек model матрицасы жылжытып, айналдырады, сондықтан камера қозғалғанда кубтардың әлемдік орны өзгермейді. Тереңдік буфері қосулы болғандықтан, жақын және алыс беттер дұрыс көрінеді.

### Қорғаудағы сұрақтар

1. Тұрақты нысана режимінде A камераны қайда апарады? Камераны координат басын айнала сол жаққа қарай доға бойымен жылжытады; камера нысанаға қарап тұрғандықтан бұл орбита сияқты көрінеді.
2. Орбиталық камера қайда пайдалы? 3D редакторда немесе CAD-та объектіні айналдыра қарап шығуға пайдалы.
3. Жоғары қозғалыстың қай түрі таңдалды? Әлемнің Y осі, яғни (0,1,0). Қарапайым FPS/адам камерасында бұл жоғары-төмен қозғалысты тік ұстайды; ұшақ симуляторында камераның өз camUp бағытын пайдалану оның еңкеюін сақтайды.
4. Ctrl көбейткішін dt-ге дейін қойса нәтиже өзгере ме? Жоқ. 2.5 * 2 * dt пен (2.5 * dt) * 2 бірдей; екеуінде де жылдамдық кадр уақытымен масштабталады.

## Құрастыру

Бұл жобаға C++17, GLFW, GLAD және GLM керек. Осы кітапханалар орнатылған CMake ортасында:

    cmake -S . -B build
    cmake --build build --config Debug --target week9

Осы папкадағы CMakeLists.txt week9 executable файлын жасайды. Репозиторийдің негізгі CMake конфигурациясына қосу үшін түбірлік конфигурациядан осы папканы add_subdirectory(week9) арқылы енгізуге болады.

## Скриншоттар

Бағдарламаны іске қосып, бастапқы сахнаны, W/A/D қозғалысын және M салыстыру режимін тексергеннен кейін осы жерге нақты орындалу скриншоттарын қосу керек. Бұл ортада OpenGL бағдарламасын іске қосып, экраннан нақты скриншот түсіру мүмкін болмады; жалған скриншот қоспадым.
